# Data

## Demo dataset
`demo_transit_delay.csv` is a **synthetic, reproducible demonstration dataset** generated by `src/generate_demo_data.py`.
It is included so the repository can be run immediately without credentials or a live API.

It is **not** presented as real transit observations.

## Recommended public secondary-data sources for the final college run
1. Pune GTFS case-study repository:
   https://github.com/charvibannur/GTFS-Project
   The repository documents Pune GTFS schedule data and contains a `FINAL_DATASET.csv` derived from Pune transit data.
2. Delhi Bus Transit Data Enhanced for ML:
   https://www.kaggle.com/datasets/adarshdubey001/delhi-bus-transit-data-enhanced-for-ml
3. GTFS / GTFS-Realtime specification:
   https://gtfs.org/documentation/overview/

For a real delay target, combine scheduled GTFS data with GTFS-Realtime Trip Updates/StopTimeUpdates, because GTFS-Realtime explicitly carries schedule deviation (`delay`) values.
